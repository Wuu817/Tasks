## 我做的修改
1. 把核心计算封装为 `calculate(xs, ys)`，让同一算法既能被命令行调用，也能被 `test.py` 直接测试。
2. 在函数中先检查两列长度是否相等，是否至少有两对数据，再计算 “n”，两列平均值，偏差平方和以及偏差乘积和。最终用"r = prod / sqrt(dx * dy)" 得到相关系数。若某一列为常量，分母为零，程序给出错误。
3. 添加 `if __name__ == "__main__":`，使导入 `calculate` 时不会顺便运行读取文件和打印结果的代码。
4. 用 `argparse` 接收 `--config`。读取配置后，按照 `input_csv` 与配置文件所在目录组合 CSV 路径；如果 `input_csv` 已是绝对路径，则直接使用它。
5. 用 `csv.DictReader` 按表头读取指定的两列，把每一行的文本转成浮点数，再送进 `calculate`。
6. 对文件不存在、空配置、空 CSV、列名不匹配、非数字、数据量不足和常量列等情况给出错误提示并以非零状态退出。

## 如何运行

在 `M0/M0-2` 文件夹中运行示例数据：

```bash
python3 legacy_corr.py --config config.yaml
```

使用其他配置文件时，把 `config.yaml` 换成该文件的路径。程序会从配置文件读取 CSV 的文件名和要计算的列名；`--config` 本身指定的是 YAML 配置文件，不是 CSV 文件。

## 输入文件格式

YAML 中的 `input_csv` 写 CSV 文件名或路径；`columns.x`、`columns.y` 分别写要计算的两列的表头名称。例如：

```yaml
input_csv: "sample_data.csv"
columns:
  x: "sensor_a"
  y: "sensor_b"
```

如果 `input_csv` 是相对路径，程序会从 YAML 所在文件夹寻找 CSV；也可以填写 CSV 的绝对路径。CSV 第一行必须是表头，包含与 `columns.x`、`columns.y` **完全一致**的列名（包括大小写）。这两列的数据要能转换成数字，至少需要两行数据；任意一列的值全部相同时，相关系数无法计算。其他列可以存在，程序不会参与计算。

## 输出结果怎么看

程序会打印 `n`、`mean_x`、`mean_y` 和 `r`。`n` 是参与计算的数据行数；两个 `mean` 分别是 x 列和 y 列的平均值；`r` 是两列的皮尔逊相关系数，范围是 **-1 到 1**。`r` 接近 1 表示较强的正向线性关系，接近 -1 表示较强的反向线性关系，接近 0 表示线性关系较弱。它描述的是线性关系，不代表一列的变化造成了另一列变化。
