# M0-3 传感器脚本问题报告（初稿）

## 缺陷记录
### 1. 读取的列名大小写与 CSV 不一致
**原位置：第 37 行。**
原代码用 `row["Value"]` 读取传感器数值，但输入 CSV 的表头是小写的 `value`。`csv.DictReader` 会把表头原样作为字典的键；`"Value"` 和 `"value"` 是两个不同的键。因此，程序读到第一行数据时会发生 `KeyError: 'Value'`。
将它改为 `row["value"]`，使代码使用的列名与 CSV 表头完全一致。
### 2. 没有处理“没有数据行”的情况
**原位置：第 47 行计算平均值之前。**
程序用 `mean = total / len(data)` 计算平均值。如果 CSV 只有表头、没有数据行，`data` 就是空列表，`len(data)` 等于 0，程序会在这里发生除零错误。
修复方法是在计算平均值之前检查 `data`。如果没有读到数据，就输出清楚的错误信息并结束程序；只有读到了数据，才继续计算。
### 3. 标准差的计算公式写错了
**原位置：第 50～53 行。**
原代码累加的是 `v - mean`，最后再除以数据条数。数据相对平均值的正偏差和负偏差会互相抵消，所以这样算出的值通常接近 0，**不是标准差**。
正确做法是先累加每个偏差的平方，即 `(v - mean) ** 2`，除以数据条数后再开平方。修复后的标准差才能用于判断离群值。
### 4. 只检查了偏大的离群值
**原位置：第 57 行。**
原条件是 `v > mean + 2 * std`。它只能识别比平均值高出两个标准差以上的数据，不能识别比平均值低出两个标准差以上的数据。例如平均值为 `50`、标准差为 `10` 时，大于 `70` 的值会被排除，但小于 `30` 的值也应被排除，原条件却会保留它们。
题目要求根据数值与平均值的**距离**判断。因此，保留正常值的条件应为 `abs(v - mean) <= 2 * std`。`abs` 取绝对值，让偏高和偏低的数据接受同一套判断。
### 5. 遍历 `data` 时又从 `data` 中删除元素
**原位置：第 56～58 行。**
原代码一边执行 `for v in data`，一边执行 `data.remove(v)`。删除一个元素后，后面的元素会向前移动，而循环会继续前进，可能跳过紧挨着的下一个值。这会导致部分离群值没有被检查。
另外，时间保存在 `times`，数值保存在 `data`。只从 `data` 删除数值，不同步处理对应时间，也会破坏两者的对应关系。修复时不再修改正在遍历的 `data`，而是逐个检查原数据，把符合条件的时间和值一起加入 `cleaned`。
### 6. `cleaned` 列表始终是空的
**原位置：第 28 行创建列表，以及第 65 行使用列表。**
程序创建了 `cleaned = []`，写输出 CSV 时也遍历 `cleaned`，但中间从未向它加入任何数据。因此，即使程序运行到了写文件的步骤，输出文件也只有 `time,value` 表头，没有数据行。
修复方法是在筛选时，把保留的数据作为一对值加入列表，例如 `cleaned.append([times[i], v])`。其中 `times[i]` 是这条数据的时间，`v` 是对应的传感器数值。这样 `cleaned` 中的每个元素就是输出 CSV 的一整行。
### 7. 输出路径被拼成了 `/out/cleaned_data.csv`
**原位置：第 61 行。**
原代码是 `os.path.join("/", OUTPUT_DIR, OUTPUT_FILE)`。第一个参数 `"/"` 表示文件系统的根目录，所以结果是绝对路径 `/out/cleaned_data.csv`，并非当前项目文件夹里的 `out/cleaned_data.csv`。如果系统根目录下没有 `out` 文件夹，接下来的 `open(output_path, "w")` 就会报错。
题目要求输出文件保存在当前工作目录。修复后让 `output_path = OUTPUT_FILE`，即使用文件名 `cleaned_data.csv`。此时程序会把文件写到**运行命令时终端所在的目录**。
### 8. 写 CSV 时把一整行又包进了一个列表
**原位置：第 65～66 行。**
修好第 6 处后，`cleaned` 中的一个元素会是 `[时间, 数值]`，例如 `[0.1, 43.2612]`。原代码却写成 `writer.writerow([v])`。这里的 `v` 已经是一整行；外面再加一层方括号，就变成 `[[0.1, 43.2612]]`。CSV 写入器会把它当作**一个字段**，而表头明明有 `time` 和 `value` 两列。
应改为 `writer.writerow(v)`，让时间和值分别写入两列。原程序因为第 6 处导致 `cleaned` 为空，通常还执行不到这一行的写入操作；给 `cleaned` 加入数据后，这处问题才会显现。
除了这些主要缺陷，还补了输入错误处理：找不到 CSV 时显示文件名；表头缺少 `time` 或 `value` 时指出列名问题；时间或数值无法转换成数字时停止并提示原因。这些处理是为了满足题目“不显示裸 `Traceback`”的要求。

## 修复后的处理顺序
1. 用 `csv.DictReader` 读取 CSV，检查表头并把 `time`，`value` 转成数字，分别保存到 `times`，`data`。
2. 先检查数据量，再计算原始数据的平均值和标准差。
3. 逐个检查 `abs(v - mean) <= 2 * std`；符合条件的记录连同对应时间一起放入 `cleaned`。
4. 写出表头 `time,value`，随后逐行写出清洗后的时间和值，并打印统计摘要。
