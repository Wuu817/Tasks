# 数据采集与标注报告

## 1. 任务与类别

本项目采用YOLO11n完成六类日常物品的目标检测，输出类别、置信度及边界框坐标。同一画面允许存在多个目标。

| ID | 类别 | 实际物品 |
|---|---|---|
| 0 | coca_cola | 可口可乐 |
| 1 | pepsi | 百事可乐 |
| 2 | sprite | 雪碧 |
| 3 | cup | 杯子 |
| 4 | tissue | 纸巾 |
| 5 | ointment | 药膏 |

可口可乐与百事可乐外形相近，是本项目重点关注的潜在易混类别。

## 2. 数据采集与扩充

数据由本人自行拍摄和标注。初期数据以单目标图片为主，发现模型在复杂多目标场景下表现较差后，额外采集了200张多目标图片，包含811个标注框。

最终数据集包含940张图片、1551个标注目标。

采集背景包括木纹桌面、门板和床架等，并改变物体的摆放位置、拍摄角度、距离及目标组合。新增多目标图片包含部分遮挡场景。

## 3. 类别分布

| 类别 | 标注框数量 |
|---|---:|
| coca_cola | 269 |
| pepsi | 277 |
| sprite | 273 |
| cup | 249 |
| tissue | 242 |
| ointment | 241 |
| 合计 | 1551 |

六类标注实例数量接近，没有明显的类别数量长尾问题，因此没有单独进行类别过采样或加权损失实验，主要通过补充复杂场景数据改善模型表现。

## 4. 标注方法

使用LabelImg进行人工标注。
标注采用YOLO TXT格式，每行包含：
`class_id center_x center_y width height`
其中中心坐标及宽高均归一化到0～1。
