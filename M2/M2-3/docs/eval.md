# 模型评估与错误分析报告

## 1. 评估方法

使用最终测试集94张图片、154个标注目标进行评估。
TP表示类别正确且检测框与真实框的IoU达到阈值的匹配结果；FP表示未正确匹配的预测框；FN表示漏检的真实目标。
Precision、Recall及F1计算公式分别为：
- Precision = TP / (TP + FP)
- Recall = TP / (TP + FN)
- F1 = 2PR / (P + R)

mAP@0.5使用IoU=0.5进行评价；mAP@0.5:0.95综合0.5至0.95共10个IoU阈值，更严格地衡量检测框定位质量。

小目标像素数量有限，相同的坐标误差可能导致更明显的IoU下降，因此在较高IoU阈值下更容易出现AP降低。

## 5. 失败原因分析
在94张测试图片中，使用conf=0.25、IoU=0.50进行统计，共发现9张包含检测错误的图片，其中7个FP、2个FN。

### 5.1 漏检问题

**1. multi_test_009：药膏漏检**

药膏位于纸巾盒后方，大部分包装被遮挡，仅有顶部狭窄区域可见。由于药膏的完整轮廓、包装文字和纹理特征大量缺失，模型难以从剩余区域识别目标。

改进方向：补充不同遮挡程度的药膏图片，增强模型对局部可见目标的识别能力。

**2. multi_test_020：杯子漏检**

杯子处于多个物体密集排列的场景中，前方饮料罐遮挡了杯身大部分区域，导致其外形轮廓不完整。模型正确识别了其他目标，但未检测出杯子。

改进方向：增加多个物体相互遮挡的训练样本，尤其是杯子仅部分露出的场景。

### 5.2 重复检测问题

**3. multi_test_002：可口可乐重复检测**

模型正确检测出了可口可乐，同时在其上方生成了一个范围更大的可口可乐框，覆盖部分背景纸箱。两个预测框的位置和尺寸存在明显差异，可能因相互IoU较低而没有被NMS消除。

**4. ointment_094：药膏重复检测**

模型对同一支药膏生成了两个检测框，其中一个接近真实目标边界，另一个明显偏大，包含周围地板。这说明模型对目标范围的判断不一致，且冗余框未被NMS过滤。

改进方向：检查重复框之间的IoU及NMS阈值，分析是否能够在不影响相邻真实目标的情况下消除冗余预测。

### 5.3 背景误检问题

**5. pepsi_122：纸箱被误检为药膏**

图片中百事可乐检测正确，但背景中的绿色纸箱被识别为药膏，置信度约为0.71。

纸箱具有竖直的长方形结构，其绿色图案与文字形成明显纹理。模型可能过度依赖局部形状和纹理特征，未充分区分纸箱与药膏的整体外观。

**6. pepsi_109：相同纸箱再次被误检为药膏**

图片背景与上一案例相似，绿色纸箱再次被识别为药膏，置信度约为0.49。

相同干扰物在不同图片中重复触发误检，说明这不是单次随机错误，而是模型对该背景物体存在一定的识别偏差。

**7. sprite_037：绿色纸箱被误检为雪碧**

模型正确检测出前景雪碧罐，同时将后方绿色纸箱误检为另一罐雪碧，置信度约为0.26。

纸箱与雪碧包装具有相近的绿色区域，且都呈现竖向结构。模型可能将包装颜色和局部纹理错误组合为雪碧特征。

**8. cup_120：电脑屏幕被误检为可口可乐**

模型正确检测出不锈钢杯，但将电脑屏幕左侧的一条狭长显示区域误检为可口可乐，置信度约为0.49。

错误框覆盖的是屏幕内容，而非真实饮料罐。该区域具有明显的竖向边界、深色背景和局部亮色图案，可能与模型学到的罐装饮料局部特征相似。

**9. sprite_120：电脑屏幕被误检为百事可乐**

模型正确检测出前景雪碧，但在其右侧电脑屏幕的一条竖向区域生成了百事可乐预测框，置信度约为0.42。

该区域包含深浅交替的界面内容和明显的竖向结构，可能触发了模型对百事可乐包装特征的错误判断。

### 5.4 原因总结与改进方向

本次失败样本主要反映三个问题：

1. "遮挡鲁棒性不足"：药膏和杯子被大面积遮挡时，模型无法充分利用剩余可见特征，导致漏检。
2. "定位与后处理不完善"：部分目标产生尺寸差异较大的重复框，NMS未能完全消除冗余结果。
3. "背景特征干扰"：绿色纸箱和电脑显示界面多次触发错误预测，说明模型对部分背景形状、颜色和纹理的区分能力不足。

最值得优先改进的是背景误检。可以在训练集中补充不包含六类目标的纸箱、电脑屏幕等负样本，使模型学会区分具有相似局部特征的背景物体和真实目标。

其次，应补充部分遮挡样本，并检查重复检测框与NMS参数之间的关系。
