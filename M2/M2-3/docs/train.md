# 模型训练报告

## 1. 模型选择

本项目采用Ultralytics YOLO11n，使用官方预训练权重`yolo11n.pt`。
YOLO11n的标准检测模型约有261.6万个参数、6.5 GFLOPs，模型规模较小，能够兼顾检测精度与CPU推理速度。
模型来源：https://docs.ultralytics.com/models/yolo11/
Ultralytics提供AGPL-3.0及Enterprise许可方式

## 2. 训练环境
- Ubuntu 24.04
- Python 3.12
- PyTorch、Ultralytics
- NVIDIA RTX 5060 Laptop GPU
模型使用GPU训练，最终部署采用CPU推理。

## 3. 训练过程

训练分为三个阶段。
第一阶段使用90张已标注图片，从官方YOLO11n预训练权重开始训练50轮，得到辅助标注所需的初步模型。
第二阶段扩充至740张图片，完成第一版正式训练。第一版模型在单目标场景表现较好，但对复杂多目标场景适应不足。
第三阶段补充200张多目标图片，总数据量达到940张、1551个标注目标，并在第一版最佳权重的基础上继续微调，得到最终模型`models/best.pt`。

最终微调参数：

| 参数 | 数值 |
| 模型 | YOLO11n |
| 数据集 | dataset/final_v2/data.yaml |
| 输入尺寸 | 640×640 |
| 最大Epoch | 100 |
| Batch Size | 16 |
| 优化器 | AdamW |
| 初始学习率 | 0.0005 |
| 学习率调度 | 余弦退火 |
| Patience | 20 |
| 随机种子 | 42 |
| Workers | 4 |

最佳权重约出现在第74轮，训练在第94轮提前停止。

训练结果保存有`results.csv`、`results.png`和`args.yaml`。

## ## 4. 数据增强
本项目使用Ultralytics内置的数据增强机制，在训练过程中自动对输入图像进行随机变换。
实际使用的增强方式包括：
1. HSV增强：色相变化参数为0.015，饱和度变化参数为0.7，亮度变化参数为0.4，用于提高模型对不同颜色和光照条件的适应能力。
2. 平移与缩放：平移参数为0.1，缩放参数为0.5，用于增加目标位置和尺寸的变化。
3. 水平翻转：概率为0.5，增加目标方向的多样性。
4. Mosaic增强：概率为1.0，将多张图片组合成一张训练图片，提高模型对多目标场景的适应能力。
训练最后10轮关闭Mosaic，使模型在训练后期进一步适应正常图像分布。
本项目没有启用垂直翻转、旋转、剪切、透视变换、MixUp、CutMix和Copy-Paste。
本项目包含可口可乐、百事可乐和雪碧等依赖包装颜色区分的类别，因此HSV增强不宜过强，否则可能削弱不同类别之间的颜色差异。

## 5. 训练结果及过拟合分析
训练损失和验证损失总体呈下降趋势，Precision、Recall和mAP逐渐稳定，没有观察到验证损失持续上升的典型过拟合现象。
采用`patience=20`提前停止策略，避免在验证性能长期没有改善后继续进行无效训练。
最终测试集结果：
| 指标 | 数值 |
| Precision | 0.992 |
| Recall | 0.977 |
| mAP@0.5 | 0.987 |
| mAP@0.5:0.95 | 0.891 |

训练曲线保存在`runs/detect/final_v2/results.png`。

## 6. 复现方式

在项目根目录运行：

```bash
source .venv/bin/activate
python train.py
```

最终微调使用第一版最佳权重作为起点，需要保留`archive/models/best_v1.pt`，并确认`dataset/final_v2/data.yaml`中的数据路径正确。
